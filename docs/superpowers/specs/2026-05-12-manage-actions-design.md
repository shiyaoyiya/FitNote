# 管理动作页面整合设计

## 概述

将 DaySettings 组件中的"添加动作"和"排序动作"两个独立页面整合为一个统一的"管理动作"页面，减少用户操作步骤，提升体验。

## 当前实现

**现有流程：**
1. 设置弹窗 → 点击"添加动作" → 进入添加动作弹窗 → 选择动作 → 确认添加 → 返回设置
2. 设置弹窗 → 点击"排序动作" → 进入全屏排序页面 → 拖拽排序/侧滑删除 → 保存 → 返回设置

**问题：**
- 用户需要在多个页面间来回切换
- 操作分散，体验不连贯

## 新设计方案

### 页面结构

**管理动作主页面：**
```
┌─────────────────────────────────┐
│  管理动作                    ×  │  ← 标题栏
├─────────────────────────────────┤
│  💡 长按拖拽排序，左滑删除      │  ← 操作提示
├─────────────────────────────────┤
│                                 │
│  ┌─────────────────────────┐   │
│  │ 卧推              ≡     │   │  ← 已选动作列表
│  │ 深蹲              ≡     │   │     （可拖拽排序）
│  │ 硬拉              ≡     │   │     （左滑删除）
│  │ ...                     │   │
│  └─────────────────────────┘   │
│                                 │
├─────────────────────────────────┤
│  [  添加动作  ] [  保存排序  ]  │  ← 底部按钮行
└─────────────────────────────────┘
```

**添加动作弹窗：**
```
┌─────────────────────────────────┐
│  选择动作                    ×  │
├─────────────────────────────────┤
│  🔍 [搜索动作...|]             │  ← 自动聚焦
├─────────────────────────────────┤
│  ┌─────┐ ┌─────┐ ┌─────┐      │
│  │引体向上│ │哑铃飞鸟│ │...  │      │  ← 动作网格
│  └─────┘ └─────┘ └─────┘      │
├─────────────────────────────────┤
│  [    确认添加    ]            │
└─────────────────────────────────┘
```

### 交互流程

1. 用户从设置弹窗点击"管理动作"进入管理动作页面
2. 页面直接显示已选动作列表，用户可：
   - 长按拖拽调整顺序
   - 左滑显示删除按钮
3. 点击"添加动作"按钮 → 弹出添加动作弹窗，搜索框自动聚焦
4. 在弹窗中搜索/选择动作 → 点击确认添加
5. 点击"保存排序"按钮 → 保存并关闭管理动作页面

### 功能保留

- 拖拽排序功能（长按触发）
- 侧滑删除功能
- 搜索过滤功能
- 已选动作高亮显示

## 技术实现

### 组件修改

**DaySettings.vue 改造：**

1. 移除 `mode` 状态中的 `'add'` 和 `'sort'` 分离模式
2. 新增 `mode: 'manage'` 作为管理动作页面的统一模式
3. 整合排序页面和添加弹窗为父子关系：
   - 管理动作页面（原排序页面）作为主页面
   - 添加动作弹窗作为子弹窗

**设置弹窗改造：**

1. 将"添加动作"和"排序动作"两个按钮合并为一个"管理动作"按钮
2. 点击后进入管理动作页面

### 状态管理

```javascript
data() {
  return {
    mode: 'settings', // settings | manage
    showAddPopup: false, // 控制添加动作弹窗显示
    // ... 其他状态保持不变
  }
}
```

### 事件处理

- `onManageActions()`: 进入管理动作页面
- `openAddPopup()`: 打开添加动作弹窗并聚焦搜索框
- `addSelectedAction()`: 添加选中动作，添加后不关闭管理动作页面
- `saveManageActions()`: 保存排序并关闭管理动作页面

| `components/DaySettings.vue` | 修改 | 整合添加和排序功能 |

## 验收标准

1. 设置弹窗中只有一个"管理动作"按钮
2. 点击后进入管理动作页面，显示已选动作列表
3. 长按可拖拽排序，左滑可删除
4. 底部有"添加动作"和"保存排序"两个按钮
5. 点击"添加动作"弹出选择弹窗，搜索框自动聚焦
6. 选择动作后点击确认，动作添加到列表末尾
7. 点击"保存排序"保存并关闭页面
