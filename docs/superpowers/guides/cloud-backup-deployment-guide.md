## 🚀 快速开始

### 第一步：开通云开发

1. **打开微信开发者工具**
   - 使用微信开发者工具打开 FitNote 项目
   - 确保已更新到最新版本

2. **开通云开发**
   - 右键点击项目根目录
   - 选择 **"开通云开发"**
   - 阅读服务协议并确认

3. **创建云环境**
   - 在弹出的云开发控制台中
   - 点击 **"创建环境"**
   - 输入环境名称：`FitNote Cloud`（或你喜欢的名称）
   - 选择 **"按量计费"** 或 **"包年包月"**（个人使用建议包年包月，更便宜）
   - 等待环境创建完成（约1-2分钟）

4. **获取环境ID**
   - 创建成功后，你会看到环境ID
   - 格式类似：`fitnote-cloud-xxxxx`
   - **重要**：复制这个ID，后面需要用到

### 第二步：配置环境ID

打开以下文件，替换 `fitnote-cloud-xxxxx` 为你实际的环境ID：

#### 1. 更新 `utils/cloudConfig.js`

```javascript
export const CLOUD_CONFIG = {
  env: 'fitnote-cloud-xxxxx', // ← 替换为你的环境ID
  database: 'backups',
  maxBackups: 3,
}
```

#### 2. 更新 `App.vue`

找到 `wx.cloud.init()` 部分：

```javascript
// #ifdef MP-WEIXIN
if (!wx.cloud) {
  console.error('请使用 2.2.3 或以上的基础库以使用云能力')
} else {
  wx.cloud.init({
    env: 'fitnote-cloud-xxxxx', // ← 替换为你的环境ID
    traceUser: true,
  })
}
// #endif
```

### 第三步：创建云数据库集合

1. **打开云开发控制台**
   - 在微信开发者工具中，点击顶部菜单 **"云开发"**
   - 或使用快捷键 `Ctrl + Shift + 1`

2. **创建数据库集合**
   - 左侧菜单点击 **"数据库"**
   - 点击 **"添加集合"**
   - 集合名称：`backups`
   - 点击 **"确定"**

3. **配置集合权限**
   - 点击 `backups` 集合进入详情页
   - 点击 **"权限设置"** 标签
   - 选择 **"自定义安全规则"**
   - 复制以下规则：

```json
{
  "read": "doc._openid == auth.openid",
  "create": "auth.openid != null",
  "update": "doc._openid == auth.openid",
  "delete": "doc._openid == auth.openid"
}
```

4. **设置说明**
   - `read`: 只有创建者可以读取自己的记录
   - `create`: 登录用户可以创建记录
   - `update`: 只有创建者可以更新自己的记录
   - `delete`: 只有创建者可以删除自己的记录

### 第四步：部署云函数

#### 1. 创建云函数目录

确保以下目录存在：
```
cloudfunctions/
└── getOpenId/
    ├── index.js
    └── package.json
```

#### 2. 部署云函数

1. 在微信开发者工具中
2. 右键点击 `cloudfunctions/getOpenId` 文件夹
3. 选择 **"上传并部署：云端安装依赖"**
4. 等待部署完成（约10-20秒）

**注意**：如果部署失败，尝试：
- 右键点击 `cloudfunctions` 文件夹
- 选择 **"上传所有云函数"**

### 第五步：测试功能

1. **启动项目**
   - 在微信开发者工具中点击 **"编译"**
   - 确保编译没有错误

2. **进入备份页面**
   - 点击底部导航的 **"备份"** 标签

3. **切换到云端备份**
   - 点击顶部 **"云端备份"** 标签

4. **测试上传**
   - 点击 **"上传至云端"** 按钮
   - 如果是首次使用，会提示授权
   - 授权后应该能看到上传成功提示
   - 检查云数据库，应该能看到新记录

5. **测试下载**
   - 在备份列表中点击 **"下载"**
   - 选择 **"覆盖导入"** 或 **"合并导入"**
   - 验证数据是否正确恢复

6. **测试删除**
   - 点击某个备份的 **"删除"**
   - 确认删除
   - 验证备份列表更新

## 🔧 常见问题

### Q1: 提示"请使用 2.2.3 或以上的基础库"

**原因**：微信基础库版本过低

**解决**：
1. 在微信开发者工具中，点击右上角 **"详情"**
2. 勾选 **"启用自定义鼻港版本"**
3. 选择一个较新的基础库版本（如 2.28.0+）

### Q2: 云函数部署失败

**原因**：可能是网络问题或依赖安装失败

**解决**：
1. 检查网络连接
2. 尝试重新部署
3. 检查 `package.json` 是否正确
4. 查看云开发控制台的日志

### Q3: 上传失败，显示"errMsg: cloud uploadFile:fail"

**原因**：
1. 云环境未正确配置
2. 环境ID不匹配
3. 云存储权限问题

**解决**：
1. 确认环境ID配置正确
2. 检查云环境是否已创建
3. 在云开发控制台 → "存储" 中检查是否有 `backups` 目录

### Q4: 数据库查询失败

**原因**：
1. `backups` 集合未创建
2. 权限配置错误

**解决**：
1. 在云开发控制台中确认集合存在
2. 检查权限规则是否正确
3. 尝试在控制台中手动添加一条测试数据

### Q5: 看不到云端备份列表

**原因**：
1. `getOpenId` 云函数未部署
2. 云函数调用失败

**解决**：
1. 确认云函数已部署
2. 在云开发控制台 → "云函数" 中查看日志
3. 尝试重新部署云函数

### Q6: 不同用户能看到彼此的备份

**原因**：代码中缺少 openid 过滤

**解决**：
确保 `cloudBackup.js` 中的所有查询函数都包含 `_openid` 过滤：
- `listUserBackups()` - ✅ 已修复
- `countUserBackups()` - ✅ 已修复
- `deleteBackup()` - ✅ 已修复
- `downloadFromCloud()` - ✅ 已修复

## 📈 性能优化建议

### 1. 监控云开发使用量

在云开发控制台中查看：
- 云函数调用次数
- 数据库读取次数
- 云存储使用量

**免费额度**：
- 每天 500 次云函数调用
- 1GB 数据库存储
- 5GB 云存储

### 2. 优化备份频率

- 建议每隔几天备份一次，不要过于频繁
- 每次大循环结束后备份一次即可
- 避免在训练过程中频繁上传

### 3. 数据压缩（可选）

如果备份文件较大，可以考虑：
- 压缩 JSON 数据后再上传
- 只备份必要的数据
- 定期清理过期的云端备份

## 🔒 安全注意事项

1. **数据隔离**：确保每个用户只能访问自己的备份
2. **权限配置**：严格按照上述权限规则配置
3. **不要在前端暴露密钥**：所有云能力调用都通过云开发SDK完成
4. **定期检查**：在云开发控制台查看异常访问记录
