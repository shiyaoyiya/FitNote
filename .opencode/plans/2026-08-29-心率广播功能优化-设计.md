# 心率广播功能优化设计文档

## 1. 概述

本文档详细描述FitNote小程序心率广播功能的全面优化设计方案。基于用户需求，本次优化涵盖用户体验优化、性能和稳定性提升、UI设计优化三个方面。

### 1.1 优化目标

1. **用户体验优化**：改善连接流程和交互逻辑
2. **性能和稳定性**：提升蓝牙连接稳定性，改用MET公式计算热量
3. **UI设计优化**：重新设计心率按钮视觉样式

### 1.2 优化范围

- 连接流程优化（保持现有流程，微调）
- 交互逻辑优化（新增手势操作和训练指导）
- 蓝牙稳定性提升（重连机制和连接质量监控）
- MET公式热量计算（替换Keytel公式）
- 心率按钮UI重新设计（视觉样式和动画效果）

## 2. 连接流程优化

### 2.1 当前实现分析

当前连接流程已完整实现，包括：
- BLE扫描和连接
- 设备筛选（只显示支持心率服务的设备）
- 自动重连机制
- 设备ID持久化

### 2.2 优化方案

由于用户选择"保持现有流程"，本次优化将保持现有连接流程不变，仅做以下微调：

1. **优化扫描界面显示**：在设备列表中显示设备名称、信号强度等信息
2. **改进连接状态反馈**：优化连接状态提示，提供更清晰的连接进度

## 3. 交互逻辑优化

### 3.1 当前实现分析

当前交互逻辑包括：
- 心率按钮三态切换（未连接/收起/展开）
- 长按打开设置
- 点击展开/收起

### 3.2 优化方案

#### 3.2.1 手势操作增强

1. **双击手势**：双击心率按钮快速切换展开/收起状态
2. **滑动手势**：在心率按钮上左右滑动切换显示模式
3. **长按菜单**：长按显示更多选项（设置、断开连接、查看历史等）

#### 3.2.2 数据展示优化

1. **实时心率趋势**：在心率按钮上显示心率变化趋势箭头（↑上升/→稳定/↓下降）
2. **心率区间指示**：用颜色直观显示当前心率档位
3. **训练区间指导**：根据当前心率档位提供训练建议（如"保持当前强度"、"增加强度"等）

#### 3.2.3 错误处理和状态反馈

1. **连接失败提示**：提供具体的失败原因和解决建议
2. **信号弱警告**：当信号强度低于阈值时显示警告
3. **设备电量提醒**：当设备电量低时提醒用户

## 4. 蓝牙稳定性提升

### 4.1 当前实现分析

当前蓝牙连接已实现：
- 断线重连（最多3次，间隔1.5秒）
- 订阅重试（最多3次，间隔800ms）
- 设备ID持久化

### 4.2 优化方案

#### 4.2.1 智能重连策略

1. **自适应重连间隔**：根据断线原因调整重连间隔
   - 正常断线：1.5秒间隔
   - 信号弱断线：3秒间隔
   - 设备关闭断线：5秒间隔
2. **重连成功率监控**：记录重连成功率，动态调整重连策略
3. **重连失败处理**：超过最大重连次数后，提示用户手动重新连接

#### 4.2.2 连接质量监控

1. **信号强度监测**：定期获取RSSI值，评估信号质量
2. **连接状态监控**：实时监测连接状态变化
3. **数据传输质量**：监测心率数据传输的完整性和及时性

#### 4.2.3 异常处理增强

1. **连接超时处理**：设置连接超时时间（10秒），超时后自动断开
2. **错误恢复机制**：针对不同错误类型制定恢复策略
3. **设备缓存优化**：缓存已连接设备信息，提高重连成功率

## 5. MET公式热量计算

### 5.1 当前实现分析

当前使用Keytel公式计算热量：
- 男：kcal/min = (-55.0969 + 0.6309×HR + 0.1988×age + 0.2017×weightKg) / 4.184
- 女：kcal/min = (-20.4022 + 0.4472×HR - 0.1263×age + 0.074×weightKg) / 4.184

### 5.2 优化方案

#### 5.2.1 MET公式实现

**MET公式**：
- 总消耗(kcal) = MET × 体重(kg) × 时长(小时)
- 净消耗(kcal) = (MET - 1) × 体重(kg) × 时长(小时)

**1 MET定义**：
- 约等于静息代谢率
- 约等于1 kcal/(kg·小时)
- 约等于3.5 mL O₂/(kg·min)

#### 5.2.2 MET值确定方法

1. **预设运动类型**：提供常见运动类型的MET值表
   - 慢走：2.8 MET
   - 快走：4.8 MET
   - 跑步：9.3 MET
   - 跳绳：11.8 MET
   - 骑行：6.8 MET
   - 游泳：8.0 MET
   - 健身操：6.0 MET
   - 瑜伽：3.0 MET
   - 力量训练：5.0 MET
   - 等等

2. **用户自定义**：允许用户输入自定义MET值（范围1.0-20.0）

3. **心率估算MET**：根据心率估算运动强度（当用户未选择运动类型时）
   - 低强度：1.6-2.9 MET（心率<60%最大心率）
   - 中等强度：3.0-5.9 MET（心率60-80%最大心率）
   - 大强度：≥6.0 MET（心率>80%最大心率）

#### 5.2.3 热量计算策略

1. **运动开始时**：
   - 用户选择运动类型或输入MET值
   - 如果未选择，使用心率估算MET值
   - 记录开始时间和初始MET值

2. **运动过程中**：
   - 每分钟计算一次热量消耗
   - 使用公式：总消耗 = MET × 体重(kg) × 时间(小时)
   - 净消耗 = 总消耗 - 静息消耗（1 MET × 体重 × 时间）
   - 实时更新累计热量

3. **运动结束时**：
   - 计算最终总消耗和净消耗
   - 显示热量消耗统计
   - 保存到训练记录

#### 5.2.4 数据结构扩展

```javascript
// 扩展DayData心率字段
{
  // ... 现有字段
  metValue: number,           // MET值（1.0-20.0）
  activityType: string,       // 运动类型（如"跑步"、"骑行"等）
  totalCalories: number,      // 总消耗（含静息），单位kcal
  netCalories: number,        // 净消耗（不含静息），单位kcal
  metHistory: Array,          // MET值变化历史 [{met: number, timestamp: number}]
}
```

#### 5.2.5 兼容性处理

1. **向后兼容**：保留现有Keytel公式作为备选
2. **数据迁移**：现有训练记录保持不变，新记录使用MET公式
3. **用户选择**：允许用户在设置中选择热量计算公式

## 6. 心率按钮UI重新设计

### 6.1 当前实现分析

当前心率按钮：
- 52×52圆形，三态切换
- 未连接态：黄色边框+脉冲动画
- 收起态：红色边框，显示♥142
- 展开态：宽度52→280px，显示详细信息

### 6.2 优化方案

#### 6.2.1 视觉样式重新设计

1. **颜色方案**：
   - 未连接态：灰色（#6B7280）
   - 连接中态：黄色（#F59E0B）+ 旋转动画
   - 已连接态：根据心率档位动态变化
     - 热身：蓝色（#3B82F6）
     - 燃脂：绿色（#22C55E）
     - 有氧：黄色（#EAB308）
     - 无氧：橙色（#F97316）
     - 极限：红色（#EF4444）

2. **形状和阴影**：
   - 圆角：从50%调整为16px（更现代）
   - 阴影：添加柔和阴影，提升层次感
   - 边框：使用渐变边框，根据心率档位变化

3. **尺寸优化**：
   - 未连接态：48×48px（略小，更精致）
   - 收起态：48×48px
   - 展开态：280×120px（更大，显示更多信息）

#### 6.2.2 动画效果优化

1. **状态切换动画**：
   - 使用CSS transition实现平滑过渡
   - 展开/收起动画：280ms ease-out
   - 颜色变化：200ms ease-in-out

2. **心跳动画**：
   - 根据实际心率调整动画速度
   - 心率越高，动画越快
   - 添加脉冲光效，增强视觉反馈

3. **数据更新动画**：
   - 心率数字变化时使用淡入淡出效果
   - 热量数据更新时使用计数器动画

#### 6.2.3 数据显示优化

1. **心率显示**：
   - 大字体显示当前心率（如"142"）
   - 小字体显示单位（如"bpm"）
   - 心率趋势指示（↑→↓）

2. **区间条优化**：
   - 使用渐变色区间条
   - 当前档位高亮显示
   - 添加区间百分比标签

3. **附加信息**：
   - 显示当前运动类型（如"跑步"）
   - 显示训练时长（如"24:15"）
   - 显示热量消耗（如"🔥326 kcal"）

#### 6.2.4 深色模式适配

1. **颜色调整**：
   - 背景色：使用深色背景（#1F2937）
   - 文字色：使用浅色文字（#F9FAFB）
   - 边框色：适当降低饱和度

2. **对比度优化**：
   - 确保文字和背景对比度≥4.5:1
   - 重要信息使用高对比度颜色

3. **阴影效果**：
   - 深色模式下使用更柔和的阴影
   - 减少阴影的黑暗度

   - 缓解措施：性能监控，优化关键路径，减少不必要的计算

3. **用户适应风险**：UI变化可能需要用户适应期
   - 缓解措施：提供引导教程，保留经典模式选项

### 7.3 成功指标

1. **连接成功率**：提升至95%以上
2. **重连成功率**：提升至90%以上
3. **用户满意度**：通过用户反馈收集，目标评分≥4.5/5
4. **热量计算准确性**：与标准设备对比误差<10%
5. **性能指标**：心率数据处理延迟<100ms，UI响应时间<50ms
